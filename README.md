💈 BarberBook
Telegram-бот для записи в барбершоп. Клиент сам выбирает услугу, мастера, дату и свободное время. Владелец видит записи, отзывы и статистику в админ-панели.
Бот работает без базы данных: все данные хранятся в JSON-файлах и текстовом логе.
Возможности:
1)Для клиента:
Регистрация при первом /start: имя и номер телефона (кнопка «📱 Отправить контакт»).
Запись: услуга → мастер → дата (7 ближайших дней) → свободное время → подтверждение. Занятое и прошедшее время не показываются.
«📋 Мои записи»: список будущих записей с кнопкой «❌ Отменить».
«💰 Услуги и цены»: название, цена, длительность.
«📍 Контакты»: фото, адрес, часы работы, точка на карте.
«⭐️ Оставить отзыв»: оценка 1–5 звёзд кнопками, затем текст.

2)Для администратора:
Вход по команде /admin, доступ только у администратора.
Записи на сегодня и на выбранную дату.
Отмена записи с сообщением клиенту.
Рассылка всем клиентам: текст → предпросмотр → «Отправить».
Статистика за неделю: число записей, выручка, самый загруженный мастер.
Последние отзывы.
Уведомление админу о каждой новой записи и отмене.

Требования
Python 3.11 или новее
Telegram-бот с токеном от @BotFather (https://t.me/BotFather)
Telegram ID администратора (можно узнать у @userinfobot (https://t.me/userinfobot))

Зависимости
python-dotenv
Загрузка BOT_TOKEN и ADMIN_ID из файла .env
Все зависимости перечислены в requirements.txt.
